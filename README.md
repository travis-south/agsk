# agsk

Personal agent skills, installable with [skills.sh](https://skills.sh).

## Skills

- `commit-and-push` — check, commit, and push current changes with a tracker-scoped commitlint subject.
- `ship-spec` — implement an approved spec on its own branch, update tracker state, independently review each work item, and open a linked draft pull request.
- `ship-ticket` — implement one ticket on its own branch, pass correctness and simplicity reviews, and open a linked draft pull request.
- `ship-ponytail-ticket` — implement one ticket using Ponytail, pass separate correctness and simplicity reviews, and open a linked draft pull request.

## Install

```bash
npx skills@latest add travis-south/agsk
```
